# Solana Program Templates

This repository contains a collection of Solana program templates and educational resources.

## Projects

### 1. [Solana Security Bounty](./solana_security_bounty)

A comprehensive set of **5 Solana programs** demonstrating common security vulnerabilities and their secure fixes using the Anchor framework.

- **Vulnerabilities Covered**:
  - Missing Signer Checks
  - Arbitrary CPIs
  - Type Cosplay (Discriminator Mismatch)
  - PDA Validation failures
  - Re-initialization attacks
- **Includes**:
  - **Pinocchio Comparison**: A "no-std" reference implementation showing manual security checks.
  - **Frontend**: A Next.js dashboard to interact with vulnerable vs. secure instructions.
  - **Tests**: Full test suite verifying exploits and fixes.

[**Explore the Security Bounty Project »**](./solana_security_bounty)
